Design a **modern, futuristic SaaS dashboard UI** for a platform called **CodeGuardian AI – AI Code Quality & Security Reviewer**.

The platform analyzes source code using AI to detect **bugs, vulnerabilities, performance issues, and technical debt**, and provides **instant fixes, insights, and refactored code suggestions**.

The UI should look like a **professional developer tool used by companies like GitHub, Vercel, Linear, and Stripe**.

Use a **dark developer theme** with modern dashboards, charts, code editors, AI panels, and security insights.

Color palette:

* Dark background
* Neon blue, purple, and green accents
* Modern SaaS design
* Clean cards and glassmorphism elements

Typography:

* Inter or JetBrains Mono for code
* Modern minimal spacing
